# Strata vs Maya: DeepSeek V4.1 Flash и кванты Qwen3.8-Flash-Next (2–3 ноября 2026)

Машина: RTX 5090 32 ГБ (GPU 0) + RTX 5070 Ti 16 ГБ (GPU 1), Ryzen 7 9800X3D, 123 ГБ DDR5-6400 (2 канала), Fedora 44,
драйвер 615.71, CUDA 13.4 ([`../HARDWARE.md`](../HARDWARE.md)). Strata 0.1.55 (`strata-dsv41` 0.1.55 для DeepSeek),
Maya (`maya-ds4`) v1.1.37.

## Тесты
- **[`bench.py`](bench.py)** — скорость на любом OpenAI-совместимом сервере. Генерация: 3 ответа по 256 токенов
  (температура 0, без размышлений). Промпт: свежие ~2K / 8K / 32K токенов со случайной меткой в начале, чтобы ничего
  не бралось из кеша; скорость = токены промпта / время до первого токена.
- **[`reason.py`](reason.py)** — логическая задача про пять яхтсменов с размышлениями (`reasoning_effort` high,
  температура 0,6, до 32K токенов ответа). У задачи ровно одно решение, это проверено перебором
  ([`puzzle_bruteforce.py`](puzzle_bruteforce.py)). Автоматическая оценка 7 баллов: состав ответа (4) и число решений
  без условий 9/10 (3); доказательство единственности (3) проверяется вручную. Полные ответы с размышлениями лежат в
  [`reasoning-transcripts/`](reasoning-transcripts/).
- **`strata bench run`** — стандартный протокол Strata для Qwen (`strata-qwen38-thinking-v1-draft.1`): короткие
  ответы, промпты 4K и 16K, 12 проверок (JSON, точный текст, вызовы инструментов). Отчёты: [`strata-standard-bench/`](strata-standard-bench/).
- Сырые данные: [`data/results.csv`](data/results.csv) (скорость), [`data/reason.csv`](data/reason.csv) (задача).

Скорость везде в токенах в секунду. Каждая конфигурация прогнана **1–2 раза**; разброс между прогонами ~5–10 %.

## DeepSeek V4.1 Flash: Strata и Maya (контекст 1M)
Strata: набор IST-DAS 2.25 bpw (~155 ГБ весов + 111 ГБ таблицы Engram IQ4_NL), `--dspark auto`, `--prefill-chunk 16384`.
Maya: Maya-S IQ2_XXS (~178 ГБ весов + 161 ГБ Engram Q6_K), `--dspark none`, если не указано иначе.

Strata на 5090 с контекстом 8K: генерация 21,2, то есть контекст 1M отнимает ~25 % скорости генерации.

**Выводы по DeepSeek:**
1. **Strata быстрее или наравне с Maya во всех конфигурациях**, при этом её набор на ~50 ГБ меньше. На одной 5070 Ti
   Maya непригодна для длинных чатов (промпт 57 ток/с: 650K контекста читались бы ~3 часа).
2. **Лучший вариант для длинных чатов — Strata на одной 5090:** самый быстрый промпт (в 2,2 раза быстрее, чем на двух
   картах) при почти той же скорости длинной генерации (30 против 32). 5070 Ti остаётся свободной.
3. Две карты дают +38 % только на коротких ответах; `--tp 2` на паре 5090 + 5070 Ti не лучше деления по слоям.
4. DSpark в Maya на одной карте вредит: −18 % в размышлениях, −47 % на промпте 32K.
5. Генерация упирается в RAM (большая часть экспертов на CPU): 5070 Ti вместо 5090 теряет лишь 8 % на коротких ответах.
6. Все 10 запусков задачи решены верно; конфигурация на качество не влияет.

Качество (замер Strata, [`docs/NVFP4.md`](https://github.com/Niko1221/Strata), против Q8_0, 4 995 позиций):
NVFP4 GPTQ — совпадение главного токена 92,1 %, KL 0,070; UD-Q4_K_XL — 93,1 % / 0,056; IQ3_S — 87,7 % / 0,144.
NVFP4-NVIDIA там не измерялся.

**Выводы по Qwen:**
1. **Наши тесты качество не различают:** все варианты решили задачу (7/7) и прошли 12/12 проверок. Разница видна только
   в замере Strata: у IQ3_S отклонение от оригинала вдвое больше, чем у NVFP4 GPTQ.
2. **IQ3_S самый быстрый** — в 1,5–2 раза быстрее NVFP4 (меньше по размеру, в видеопамять помещается больше экспертов).
3. **NVFP4-NVIDIA на 11–17 % быстрее GPTQ**, хотя документация обещает одинаковую скорость.
4. Две карты ускоряют IQ3_S (+42 %) и NVFP4-NVIDIA (+14 %), но не GPTQ; промпт на двух картах обычно медленнее.
5. **Qwen в 3,5–6 раз быстрее DeepSeek** на той же 5090 и решил ту же задачу за 3–4,5 мин против 12,5–16 мин.

**Рекомендация:** скорость — IQ3_S на двух картах (~200 ток/с); точность — NVFP4 GPTQ на 5090; компромисс —
NVFP4-NVIDIA на двух картах (~120–140 ток/с). DeepSeek — Strata на одной 5090.

## Ограничения
- Почти все конфигурации прогнаны 1–2 раза; выводы в пределах ~10 % считать приблизительными.
- Задача и 12 проверок Strata слишком простые, чтобы различить кванты по качеству.
- Отчёт `strata bench run` для IQ3_S на двух картах не сохранился в доступном виде; скорость есть из `bench.py`.
- Энергопотребление в этой серии не снималось.
